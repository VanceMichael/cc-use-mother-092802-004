# 领域边界

贯通灾害点和风险区研判、预警叫应、转移安置与救援物资。

现有领域资料围绕以下边界组织：

- 点区双控：已登记灾害点与山区沟口、临崖陡坡、施工工地、旅游景区同等纳入清单，挂在责任网格下
- 预警叫应：按范围圈定住户与游客分组，回执幂等，逾期缺口可跨班次续办
- 转移路线与安置：指令留痕发布人，到达按人去重，容量强约束，完成须他人确认
- 力量物资前置：队伍一处一备，物资预占、领取、交接三段流转，不得双重占用
- 解除响应复盘：事件链只追加，迟到雨情不改写已发命令，解除时可还原当时全貌

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 服务不变量

`src/response_service.py` 在命令入口强制以下不变量，事实先落盘后生效：

- 同一标识重复提交且内容一致时幂等返回，内容不一致时拒绝
- 已到安全地点的人不再计入任何安置点占用
- 任务完成确认人不能是发布该指令的人
- 敏感人员信息仅相应网格与安置岗位可见，其余岗位只见脱敏名册
- 拒绝转移、通信中断、路线封闭作为事实保留，并自动生成替代任务
- 安置点容量、物资可用量不得为负，队伍不得同时承担两处前置
- 响应解除后资料与命令只读，只能复盘查询
